# 香港 Wonderland — Web3.0 虚拟经济体游戏

一个基于纯 HTML/CSS/JavaScript 的 Web3.0 虚拟经济体游戏原型。玩家在香港主题城市中通过代币、资产和市长系统构建虚拟经济与城市治理体验。

## 项目特点

- 单页游戏：可直接打开 `index.html` 运行
- 虚拟代币系统：$HKT 作为游戏内主要货币
- 资产与 NFT 概念：地标资源可交易、入股与分红
- 市长系统：玩家可轮流担任友好市长，影响城市福利与税收
- 本地存储：使用浏览器 LocalStorage 保存玩家数据

## 运行方式

1. 克隆或下载仓库
2. 在浏览器中打开 `index.html`

## 文件结构

- `index.html` — 游戏主页面与样式
- `SPEC.md` — 项目概览与设计说明
